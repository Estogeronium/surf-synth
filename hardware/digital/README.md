# Surf Synth: цифровая версия для пайки

Звук считает Raspberry Pi Pico 2, потенциометры читает АЦП MCP3008, усиливает I2S-модуль на MAX98357A. Это те же ручки Surf, Tide, Tone и Volume, что на сайте, и тот же алгоритм звука: код на C++ взят с сайта и сверен с ним.

> **Статус.** Схема нарисована и проверена по списку правил, звуковой код сверен с версией сайта на компьютере. Устройство не собиралось, прошивка на реальной Pico 2 не запускалась: компилятор Arduino-Pico из моей среды недоступен. Подробности в разделе «Что не проверено».
>
> Аналоговая версия (122 детали, без микроконтроллера) осталась в [`../analog`](../analog/README.md).

## Как это устроено

```
Питание 5 В → кнопка → ┬→ MAX98357A → динамик
                       └→ D1 → Pico 2 (VSYS) → 3,3 В → MCP3008, 4 потенциометра
Pico: звук → I2S (GP9 DIN, GP10 BCLK, GP11 LRC) → MAX98357A
Pico ← SPI0 (GP16…GP19) ← MCP3008 ← Surf, Tide, Tone, Volume
Pico GP15 → R1 → Q1 → светодиод D2 (яркость следует за волной)
```

Соединения Pico (физические номера выводов, USB сверху):

| Вывод | Назначение | Цепь |
|---|---|---|
| 12 (GP9) | DIN усилителя | I2S_DIN |
| 14 (GP10) | BCLK усилителя | I2S_BCLK |
| 15 (GP11) | LRC усилителя (всегда BCLK + 1) | I2S_LRC |
| 20 (GP15) | светодиод через R1 и Q1 | LED_CTL |
| 21 (GP16) | MISO ← DOUT MCP3008 | SPI_MISO |
| 22 (GP17) | CS MCP3008 | SPI_CS |
| 24 (GP18) | SCK → CLK MCP3008 | SPI_SCK |
| 25 (GP19) | MOSI → DIN MCP3008 | SPI_MOSI |
| 33, 38 | земля | GND |
| 36 | 3,3 В для MCP3008 и потенциометров | V3 |
| 39 | питание Pico через D1 | VSYS |

Потенциометры: вывод 1 — земля, вывод 3 — 3,3 В, средний — вход MCP3008 (CH0 Surf, CH1 Tide, CH2 Tone, CH3 Volume) с конденсатором 100 нФ на землю. Если ручка вращается «наоборот», поменяйте крайние выводы.

## Что купить

Полный список со ссылками: [`out/BOM.md`](out/BOM.md). Названия и ссылки взяты из поиска по chipdip.ru. Сами страницы я открыть не мог, поэтому остаток, цены и сроки проверьте на сайте. Для двух позиций точное подтверждение не получилось: у светодиода GNL-3014BGC найдена только страница серии, у потенциометров не подтверждены диаметр и тип оси (ручки крепятся винтом и подходят к обеим).

Всего 22 детали и ещё плата, панельки, провод, ручки, блок питания и корпус.

## Сборка

1. Впаяйте в Pico две планки штырей, в макетную плату — две панельки PBS-20 (7 отверстий между рядами), панельку DIP-16 под MCP3008 и гнездо 1 × 7 под модуль усилителя. Позиции — на листе 3.
2. Дальше диод D1 (полоса к Pico), резисторы, конденсаторы (минус электролитов — полоса на корпусе), транзистор Q1.
3. Провода по списку на листе 3 (земля и 3,3 В — общие шины). К потенциометрам, кнопке, светодиоду и гнезду питания — гибкие провода в корпус.
4. Включите питание **до** установки микросхем и проверьте: 5 В на модуле усилителя, ничего не греется.
5. Установите Pico и MCP3008, прошейте (ниже).

## Прошивка

1. Arduino IDE → «Менеджер плат» → в настройках добавьте `https://github.com/earlephilhower/arduino-pico/releases/download/global/package_rp2040_index.json`, установите «Raspberry Pi Pico/RP2040/RP2350».
2. Откройте `firmware/surf_synth/surf_synth.ino` (рядом должен лежать `surf_dsp.h`), плата — «Raspberry Pi Pico 2».
3. Зажмите BOOTSEL, подключите USB, нажмите «Загрузить». Внешнее питание на это время отключите.

## Что проверено

- **Схема:** правила проверки (ERC) и 11 проверок выводов: шина I2S, SPI0, питание 3,3 В и 5 В, подключение движков, ток светодиода и базы Q1 (см. `out/hardware.json`, раздел `checks`).
- **Звук:** C++-код собран на компьютере и сравнён с кодом сайта на трёх наборах ручек по 2 минуты звука. Громкость совпадает в пределах нескольких процентов, доли частотных полос и интервал между волнами близки, динамический диапазон волн одинаков (17,4–17,6 дБ):

| Ручки (Surf / Tide / Tone) | RMS сайт | RMS прошивка | Динамика, дБ (сайт / прошивка) | Интервал волн, с (сайт / прошивка) |
|---|---|---|---|---|
| 0,5 / 0,45 / 0,5 | 0,052 | 0,051 | 17,4 / 17,5 | 7,3 / 7,8 |
| 0,2 / 0,2 / 0,3 | 0,025 | 0,023 | 17,9 / 17,4 | 9,3 / 9,5 |
| 0,9 / 0,8 / 0,7 | 0,097 | 0,093 | 17,5 / 17,6 | 4,0 / 4,0 |

- **Интерфейс библиотек:** скетч компилируется на компьютере с заглушками, повторяющими API Arduino-Pico (`I2S::setBCLK/setDATA/setBitsPerSample/setBuffers/begin/write16`, `SPI::setRX/setTX/setSCK`, `analogWrite`); имена и сигнатуры сверены с исходниками библиотеки.

## Что не проверено

- Устройство не собиралось. Компилятор Arduino-Pico (набор инструментов для RP2350) из моей среды скачать нельзя, поэтому прошивка проверена только с заглушками.
- Загрузка процессора Pico 2 не измерялась. Оценка: звуковой код — около 2–3 % одного ядра на 32 кГц.
- Порядок выводов на плате модуля MAX98357A и рабочая полярность оси потенциометра смотрите по надписям на плате.
- Выход MAX98357A при питании 5 В на динамик 8 Ом выдаёт до 1,8 Вт; прошивка ограничивает уровень до ≈ 0,8 полной шкалы, чтобы не перегрузить динамик VISATON K 64 WP (2 Вт).

## Как пересобрать

```bash
python3 hardware/digital/tools/build.py        # схема → svg, список деталей, провода, данные для 3D
g++ -O2 -std=c++17 -o /tmp/host_test hardware/digital/firmware/test/host_test.cpp
python3 hardware/digital/firmware/test/compare.py   # сравнение с сайтом (нужны Playwright и запущенный vite dev)
```

Правки вносятся в `tools/circuit.py` (схема), `tools/layout.py` (расстановка), `tools/catalog.py` (названия и ссылки).
