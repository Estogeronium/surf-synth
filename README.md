# Surf Synth

Синтезатор морского прибоя для сайта: розовый шум, который накатывает и отступает волнами. Интерфейс — 3D-прибор: белый корпус, один акцентный цвет `#00CFC1`, крутилки.

Весь звук синтезируется в браузере (Web Audio API), без сэмплов. Интерфейс — Three.js, без внешних ассетов.

## Управление

| Элемент | Действие |
|---|---|
| **Power** | включить / выключить (плавный fade) |
| **Surf** | активность прибоя: от штиля до шторма (сила волн, пена, яркость) |
| **Tide** | частота волн: от одной за ~14 с до одной за ~3 с |
| **Tone** | тембр: тёмный ↔ светлый прибой |
| **Volume** | громкость |

Крутилки: тянуть мышью или пальцем (Shift — точнее), колесо мыши, либо клавиатура: Tab к нужному регулятору и стрелки. Положения сохраняются в `localStorage`. Если WebGL недоступен, показываются обычные ползунки.

## Версия для пайки

Кнопка **«Внутри»** показывает, как устроено устройство, если собрать его из деталей: 3D-плата с модулями, проводами и ручками, список покупок со ссылками на chipdip.ru, схема и порядок сборки. Цифровая версия (Raspberry Pi Pico 2) описана в [`hardware/digital`](hardware/digital/README.md); аналоговая осталась в [`hardware/analog`](hardware/analog/README.md).

## Как устроен звук (в браузере)

```
розовый шум → lowpass → огибающая волны ───────┐
розовый шум → highpass → огибающая пены ───────┴→ power → volume → limiter
```

Каждая волна — одна запланированная кривая: быстрый накат и длинное затухание. Длительность и сила каждой волны случайны, поэтому звук не повторяется. Та же огибающая открывает частоту среза фильтра: на гребне шум яркий, в отливе глухой. Код: `src/audio/surf-engine.js`.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Встраивание на сайт

Сборка использует относительные пути, поэтому `dist/` работает из любого подкаталога. После деплоя на GitHub Pages (Settings → Pages → Source: GitHub Actions):

```html
<iframe src="https://estogeronium.github.io/surf-synth/"
        allow="autoplay" style="border:0;width:100%;height:480px" title="Surf Synth"></iframe>
```

Звук стартует только после клика по кнопке Power (требование браузеров).
